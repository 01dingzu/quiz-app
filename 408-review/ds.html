考点 1 · 线性表、栈与队列

选择题高频 · 循环队列与出入栈序列是常客

顺序表 vs 链表：顺序表支持随机访问 O(1)、插删需移动 O(n)；链表插删改指针 O(1)（定位 O(n)）、不支持随机访问。按位序访问选顺序表，频繁插删选链表。

出入栈序列：n 个不同元素依次入栈，合法出栈序列数 = 卡特兰数 C(2n,n)/(n+1)。判断合法性：任何时刻出栈元素只能是"还未出栈且已入栈"的最大者之后……直接模拟即可。

循环队列：队满条件（牺牲一格）(rear+1)%size == front；元素个数 = (rear − front + size) % size。此时最多存 size − 1 个元素。

矩阵压缩：对称矩阵下三角（1 起，i ≥ j）按行存到一维数组：k = i(i−1)/2 + j（k 从 1 计）。

例题 · 出栈序列合法性推演
入栈顺序为 1、2、3、4，判断出栈序列 3, 1, 4, 2 是否合法。
展开完整推演 
目标序列第一个是 3：
  依次入栈 1, 2, 3 → 栈内(底→顶): 1, 2, 3
  弹出 3 ✓ 栈: 1, 2
第二个是 1：但当前栈顶是 2，且 4 还未入栈
  （入栈顺序固定，1 已被 2 压在下面）
  既弹不出 1，也不可能再入栈改变栈顶顺序
  ⇒ 非法

判断技巧：序列中某个元素出栈后，它下面"比它小的元素"必须已按降序…更快的通用办法是直接模拟：维护一个"下一个待入栈元素"指针，逐个比对目标序列，能模拟到底就合法。

答：不合法。1 出栈前 2 必须先出栈，而目标序列要求 1 先出。

练习题

考点 2 · 树与二叉树

全卷重中之重 · 二叉树性质、AVL、哈夫曼、B 树

二叉树性质：叶子数 n₀ = 度 2 结点数 n₂ + 1。完全二叉树 n 个结点高度 = ⌊log₂n⌋ + 1。

遍历：中序 + 先序（或中序 + 后序）可唯一确定二叉树；先序 + 后序不能（无法区分独子是左还是右）。

哈夫曼树：n 个叶子 → 总结点数 2n − 1，无度为 1 的结点；哈夫曼编码是前缀码（任何编码不是另一个的前缀）。

BST：中序遍历得到递增序列。AVL：任一结点平衡因子 ∈ {−1, 0, 1}，失衡按最小不平衡子树调整（LL/RR 单旋，LR/RL 双旋）。

B 树（m 阶）：根至少 2 棵子树；非根非叶至少 ⌈m/2⌉ 棵子树、⌈m/2⌉−1 个关键字；每结点至多 m 棵子树、m−1 个关键字。B+ 树：n 棵子树 n 个关键字，叶子含全部关键字并链表相连，非叶仅作索引。

例题 · AVL 插入与旋转推演
依次插入 3、2、1、4、5，画出每次失衡调整后的树形，并写出最终树的先序序列。
展开完整推演 
插 3:      3
插 2:      3(2, )        无失衡
插 1:      3(2(1,), )    结点 3 失衡 bf=2，LL 型
  → 右单旋:  2(1, 3)
插 4:      2(1, 3(,4))   无失衡
插 5:      2(1, 3(,4(,5)))
  结点 3 失衡 bf=-2，RR 型 → 左单旋:
  3 的右孩子 4 上提，3 成为 4 的左孩子
最终:      2(1, 4(3, 5))

答：先序序列 2, 1, 4, 3, 5。

口诀：LL 右旋、RR 左旋、LR 先左后右、RL 先右后左——第一个字母指插入方向。

练习题

考点 3 · 图

大题常客 · 遍历、最短路、拓扑、关键路径

存储：邻接矩阵判断两点邻接 O(1)、空间 O(n²)，适合稠密图；邻接表空间 O(n+e)，适合稀疏图。无向图邻接矩阵是对称矩阵，边数 = 非零元素数 / 2。

遍历：BFS 用队列（可求无权图单源最短路），DFS 用栈/递归。邻接矩阵下两者均 O(n²)，邻接表下均 O(n+e)。

最小生成树：Prim 逐点扩张 O(n²)，适合稠密图；Kruskal 逐边挑选 O(elog₂e)，适合稀疏图。MST 形态可能不唯一但边权之和唯一。

最短路：Dijkstra 单源、不能处理负权；Floyd 全源 O(n³)、可负权边但不能有负权回路。

拓扑与关键路径：拓扑序列一般不唯一；AOE 网关键路径 = 最长路径，关键活动满足最早开始 = 最迟开始。缩短单个关键活动不一定缩短工期（可能同时存在多条关键路径）。

例题 · Dijkstra 逐步推演
有向图：A→B=1，A→C=4，B→C=2，B→D=6，C→D=3。求 A 到 D 的最短路径与长度。
展开完整推演 
初始: dist[B]=1, dist[C]=4, dist[D]=∞
选 B(最小 1)，用 B 松弛:
  C: min(4, 1+2)=3   D: min(∞, 1+6)=7
选 C(最小 3)，用 C 松弛:
  D: min(7, 3+3)=6
选 D(6)。结束。

答：最短路径 A→B→C→D，长度 6。

易错：Dijkstra 每轮从"未确定"集合中选 dist 最小的点，一旦某点被选中其距离即最终值——这也是它容不下负权边的原因。

考点 4 · 查找

散列表 ASL 计算是大题常客

二分查找：仅适用于有序 + 顺序存储；n 个元素最多比较 ⌈log₂(n+1)⌉ 次，判定树是平衡的二叉排序树。

散列表：装填因子 α = 表中元素数 / 表长；α 越大冲突概率越高。查找效率取决于散列函数、冲突处理方法、装填因子，不直接依赖表长或元素数本身。

冲突处理：线性探测易"堆积（聚集）"；平方探测缓解堆积；拉链法无堆积、删除方便，但需额外指针空间。

ASL 计算：成功的 ASL = 各元素比较次数之和 / 元素数；不成功的 ASL = 从每个可能的散列地址出发到"空位"的比较次数之和 / 散列函数取值数。

例题 · 线性探测与 ASL 推演
散列函数 H(key) = key mod 7，表长 10，用线性探测法依次插入 14、36、42、8。画出表，并计算查找成功的平均查找长度。
展开完整推演 
14: 14%7=0 → 放 0 号位（1 次）
36: 36%7=1 → 放 1 号位（1 次）
42: 42%7=0 → 0 被占 → 1 被占 → 放 2 号位（3 次）
 8:  8%7=1 → 1 被占 → 2 被占 → 放 3 号位（3 次）
表: [14][36][42][8][ ][ ][ ][ ][ ][ ]

答：ASL成功 = (1+1+3+3)/4 = 2。

注意：比较次数 = 从散列地址开始探测到最终落位（含落位确认）的地址访问次数，不是散列值本身。

考点 5 · 排序

稳定性 + 复杂度对比是选择题固定菜

稳定的：直接插入、冒泡、归并、基数。不稳定的：简单选择、希尔、快排、堆。（口诀：稳定四君子，选择希尔快排堆不靠谱。）

快排：平均 O(nlog₂n)，基本有序（或基本逆序）时最坏 O(n²)；每趟至少确定一个元素的最终位置。

堆排序：建初始堆 O(n)，之后每次取堆顶再调整 O(log₂n)；适合取前 k 大/小元素。

归并：稳定 O(nlog₂n)，需要 O(n) 辅助空间。基数排序：d 趟"分配-收集"，与初始序列是否有序无关。

简单选择：比较次数固定 n(n−1)/2，与初始状态无关。折半插入：减少比较次数，移动次数不变。基本有序的序列首选直接插入 / 冒泡（可近 O(n)）。

例题 · 快排一趟划分推演
对 [45, 20, 60, 30, 70, 10] 以第一个元素 45 为枢轴做一趟快速划分，写出结果。
展开完整推演 
枢轴 45 暂存。i 从左找 >45，j 从右找 <45。
j: 10 < 45 停（位置 5）；i: 60 > 45 停（位置 2）
  交换 → [45, 20, 10, 30, 70, 60]
j 继续左移: 30 < 45 停（位置 3）
i 继续右移: 70 > 45 停（位置 4）
  此时 i > j，枢轴放入位置 3
结果: [30, 20, 10, 45, 70, 60]

答：一趟后 [30, 20, 10, 45, 70, 60]，45 到达最终位置，左区 {30,20,10} 右区 {70,60}。

自查法：枢轴左边全 ≤ 枢轴、右边全 ≥ 枢轴，即划分成功。

练习题

综合大题（算法设计）

限时 20 分钟 · 先写思路和伪代码再展开对照
题目：带头结点的单链表 L，结点值为整数且 |值| ≤ 表长 n。设计一个时间 O(n) 的算法，删除链表中绝对值相等的结点，只保留第一次出现的那个，结点相对次序不变。要求给出算法思想、代码，并说明空间复杂度。
展开参考答案与评分点

算法思想：利用值域有限（|值| ≤ n）这一条件，开一个长度 n+1 的标记数组 flag（初值 false）。一趟扫描：遇到值 v，若 flag[|v|] 为 false，置 true 保留；为 true 则删除当前结点。

void dedup(LinkList L, int n){
    int *flag = calloc(n+1, sizeof(int));
    LNode *p = L->next, *pre = L;
    while(p != NULL){
        int v = abs(p->data);
        if(flag[v]){            // 已出现过，删除
            pre->next = p->next;
            free(p);
            p = pre->next;
        } else {                // 首次出现，保留
            flag[v] = 1;
            pre = p;
            p = p->next;
        }
    }
    free(flag);
}

复杂度：时间 O(n)（一趟扫描）；空间 O(n)（标记数组）。若不允许辅助数组且链表无序，只能双重循环 O(n²)——审题时要抓住"|值| ≤ n"这个提示。

评分点自查：① pre 指针与删除时先保存 p->next；② 头结点处理正确（pre 从 L 开始）；③ 空间复杂度说明；④ 边界：空表、全重复。
