n₀ = n₂ + 1边数既等于 n−1（除根外每结点一条入边），又等于 n₁ + 2n₂；与 n = n₀+n₁+n₂ 相减即得只对二叉树成立
h = ⌊log₂n⌋+1前 h−1 层满：2^(h−1)−1 < n ≤ 2^h−1，两边取对数根算第 1 层
叶数 ⌈n/2⌉；双亲 ⌊i/2⌋，左孩 2i，右孩 2i+1层序编号下第 k 层是 2^(k−1) ~ 2^k−1，父子是翻倍/减半关系；后半编号都没有孩子编号从 1 起
下三角 k = i(i−1)/2 + j − 1前 i−1 行共 1+2+…+(i−1) = i(i−1)/2 个元素，再加本行第 j 个i ≥ j，下标从 1 起
WPL = 所有非叶结点权之和每次合并两最小，其和记为一个内部点；叶权每被合并一次就多算一层，累计次数恰等于深度路径长度数「边」不数「层」
最多 ⌊log₂n⌋+1 次比较每比较一次区间减半，n/2^k ≤ 1 得 k ≥ log₂n成功/失败 ASL 要分开算
⌈log₂(n!)⌉ ≈ n·log₂n − 1.44nn! 种排列各需一个判定树叶，树高至少 log₂(n!)，再用 Stirling 展开只约束比较排序
α = n/m；ASL成功 ≈ ½(1+1/(1−α))，失败 ≈ ½(1+1/(1−α)²)探测命中空槽服从几何分布，空槽率 1−α，平均探测次数 1/(1−α)成功与失败公式别记反
个数 (rear−front+m)%m；队满 (rear+1)%m = front牺牲一格才能区分空与满；取模把环拉成直线看清 rear 指向队尾还是队尾后一位

n 位补码：−2^(n−1) ~ 2^(n−1)−1把符号位看成权 −2^(n−1)，其余 n−1 位全 1 是 2^(n−1)−1，两端相加原码/反码有 ±0，补码没有
[x]移 = 2^(n−1)+x；N = (−1)^s·1.M·2^(E−127)整体平移使负数变正便于比较阶码；E 只取 1~254（0/255 留给非规格化与无穷/NaN），故真指数 −126 ~ +127双精度偏置是 1023
2^k ≥ n+k+1；检 t 错 d ≥ t+1，纠 t 错 d ≥ 2t+1k 位校验共 2^k 种症状，要覆盖 n+k 个位置各错一种再加无错；纠错要求各码字半径 t 的球互不相交n 是信息位，不是总位数
地址 = tag + 组号 s + 块内 b；s = log₂组数，b = log₂块大小；t = h·t_c+(1−h)·t_m主存块按块号 mod 组数入组，块号低 s 位即组号、高位是 tag；平均时间是命中/未命中的全概率加权串行访问与并行访问结果不同
T = (k+n−1)Δt；S = nk/(k+n−1) → k；E = n/(k+n−1)首条要 k 拍充满流水线，之后每拍流出一条；串行需 nk 拍，一除就是加速比有冒险时要加停顿拍
CPU时间 = I×CPI/f；MIPS = f/(CPI×10⁶)总周期数 = 指令数 × 平均周期数，再除以频率换成秒CPI 要按指令类型加权
S = 1/[(1−f) + f/s]归一化原时间为 1，不可加速部分 1−f 不变，可加速部分压缩为 f/sf 是「占比」不是「倍数」
带宽 = (宽度/8) × 频率 × 每周期传送次数一次传多少字节 × 每秒传几次宽度常给「位」，要除以 8
平均存取 = 寻道 + 1/(2r) + 数据量/(r×每道容量)平均等半圈；传输率 = 每道容量 × 每秒转速r 用「转/秒」

周转 = 完成−到达；带权 = 周转/服务定义；除以服务时间消掉长作业天然吃亏的偏差等待 = 周转 − 服务
响应比 = (等待+服务)/服务 = 1 + 等待/服务等得久分子变大、短作业分母小，两个诉求同时被照顾每次调度完要重算
不死锁最少同类资源 = n(m−1)+1最坏每进程各占 m−1 个、都差最后 1 个；多给 1 个必有一进程凑齐，完成后释放唤醒全链只对「同类资源、一次性申请」成立
Need = Max − Allocation；从 Work = Available 反复找 Need ≤ Work模拟「假设批给它，它能否完成并归还」，能排完就存在安全序列安全序列不唯一，找到一个即可
页号 = ⌊逻辑地址/页大小⌋；物理地址 = 页框号×页大小 + 页内偏移页内偏移映射前后不变，只替换页框基址页大小通常是 2 的幂，直接切低位
页表项数 = 2^(页号位数)；每级索引 = log₂(页大小/表项大小)页表必须刚好装进一页，才能用一级索引直接定位下一级别忘算页表自身占几页
无 TLB：2t；有 TLB：h(t_TLB+t)+(1−h)(t_TLB+2t)命中只访存一次，未命中多访一次页表，再按命中率加权看清 TLB 查询是否与访存重叠

计算机网络25 分 · 率、时延、窗口与地址10 条
公式怎么推出来的考场提醒
R = 2W·log₂V；C = W·log₂(1+S/N)带宽 W 的信道每秒最多 2W 个独立码元（采样定理），每码元带 log₂V 位；香农是噪声下的信息论上限。dB = 10·log₁₀(S/N)，故 S/N = 10^(dB/10)先由 dB 还原线性比值
发送 = L/R；传播 = d/v；时延带宽积 = 传播时延 × R定义；时延带宽积是链路上「在途」的最大比特数先统一 Mb 与 MB、ms 与 μs
停等 U = 1/(1+2a)，a = 传播/发送；窗口 U = min(1, W/(1+2a))发完一帧要 L/R，最早也要再等 2×传播时延才收到 ACK；窗口内 W 帧可连发填补空档a 是两个时延之比，别写成倒数
GBN 发送窗 ≤ 2^k−1；SR 收发窗各 ≤ 2^(k−1)k 位序号只有 2^k 个编号；SR 要求收发窗口之和不超编号空间，否则新帧与重传旧帧序号混淆GBN 接收窗恒为 1
最小帧长 = 2τ×R（τ 为单程传播时延）最远端冲突要 2τ 才传回来，帧必须此刻还在发才能检测到；10Mb/s × 51.2μs = 512bit = 64Bτ 是单程，2τ 是往返
r ∈ [0, 2^k−1]，k = min(重传次数, 10)；退避 512 bit time × r冲突越多随机范围翻倍，压低再次碰撞概率；16 次仍失败则丢弃k 上限 10，不是无限翻倍
/n：地址数 2^(32−n)，可用主机数 = 2^(32−n) − 2主机位全 0 是网络地址、全 1 是广播地址，各占掉一个/31、/32 点对点链路例外
片偏移 = 该片数据首字节 / 8偏移字段以 8 字节为单位计数，故除末片外每片数据长度必须是 8 的倍数偏移不含首部长度
D_x(y) = min_v { c(x,v) + D_v(y) }到 y 的最优路径必经某个邻居 v，取「到 v 的链路代价 + v 通告的距离」最小坏消息传得慢，要逐轮迭代
RTO = RTT_s + 4·RTT_D；慢启动 cwnd 每 RTT 翻倍；吞吐 ≈ min(cwnd, rwnd)/RTT指数加权平滑滤抖动、加 4 倍偏差覆盖波动；每收一个 ACK 加 1 MSS，一轮 ACK 数约等于 cwnd 故指数增长超时 ssthresh = cwnd/2 且 cwnd 回 1

三条抓手（忘了公式就现推）

范围 / 容量类都从「位数或边数守恒」来：补码看符号位权、树看边数、Cache 看地址位数、CIDR 看主机位。

时间类都是「一次多少 × 多少次」：流水线 k+(n−1) 拍、CPU 时间 I×CPI/f、磁盘等半圈、CSMA/CD 等 2τ。

率类都是「有效部分 / 总部分」：命中率加权、停等利用率 1/(1+2a)、Amdahl 的 (1−f)+f/s、窗口占编号空间的比例。

还有几类「看着像公式、其实是逐层套定义」

B 树高度与最少关键字数（每层至少 ⌈m/2⌉ 棵子树递推）、AOE 关键路径 ve/vl/e/l、磁盘调度平均寻道长度、UDP 与 IP 检验和的反码加法、CIDR 最长前缀聚合、扩展操作码条数、Cache 与页表的组合命中率。做法都是分层算，不必背结论。

单位先统一：速率 Mb/s = 10⁶ b/s，容量 1K = 2¹⁰，1B = 8b。时延题几乎每年都有人栽在 Mb 与 MB、ms 与 μs 上。
